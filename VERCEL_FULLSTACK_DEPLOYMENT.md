## 🎯 Step-by-Step Vercel Deployment

### Step 1: Push Your Code to GitHub
Make sure all your latest changes are pushed to GitHub:
```bash
git add .
git commit -m "Prepare for Vercel deployment"
git push origin main
```

### Step 2: Go to Vercel
1. **Visit [vercel.com](https://vercel.com)**
2. **Click "Sign Up"**
3. **Choose "Continue with GitHub"**
4. **No credit card required!**

### Step 3: Import Your Repository
1. **Click "New Project"**
2. **Find your portfolio repository**
3. **Click "Import"**

### Step 4: Configure Project Settings
Vercel will auto-detect your project. Use these settings:

**Framework Preset**: `Other`
**Root Directory**: `./` (leave as default)
**Build Command**: `npm run vercel-build`
**Output Directory**: `client`
**Install Command**: `npm install`

### Step 5: Add Environment Variables
Click **"Environment Variables"** and add these 5 variables:

**Variable 1:**
- **Name**: `NODE_ENV`
- **Value**: `production`

**Variable 2:**
- **Name**: `EMAIL_USER`
- **Value**: `mesayboja3@gmail.com`

**Variable 3:**
- **Name**: `EMAIL_PASS`
- **Value**: `yhtb ppuk uaic wwot`

**Variable 4:**
- **Name**: `MONGODB_URI`
- **Value**: `mongodb+srv://mesay-boja_1:mesayportfolio@cluster0.jeihu31.mongodb.net/portfolio?appName=Cluster0`

**Variable 5:**
- **Name**: `PORT`
- **Value**: `3000`

### Step 6: Deploy!
1. **Click "Deploy"**
2. **Wait 3-5 minutes** for deployment
3. **Get your live URL!**
